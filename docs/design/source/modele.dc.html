01 · Ce qu'il fait

Une sortie en entrée, une phrase en sortie.

Le modèle reçoit la commande, son code de retour et sa sortie. Il répond par une seule ligne de quinze mots au plus : le résultat d'abord, puis un détail utile. Les noms et les nombres sont recopiés tels quels.

02 · Pourquoi petit

Assez petit pour tourner à côté de votre travail.

Un assistant de terminal tourne pendant que vous travaillez, souvent sur le processeur d'un portable. Les petits modèles qui y tiennent paraphrasent, perdent les chiffres ou inventent. steph-speak est entraîné pour l'inverse : le résultat d'abord, les noms et les nombres exacts, rien d'inventé.

Dans steph, il ne travaille pas seul. Des règles écrites en code résument déjà une grande partie des sorties. steph-speak reçoit le reste : les sorties longues, les erreurs, les questions sur la session.

07 · Steph Speak Bench

Un banc d'essai ouvert, pour tous les modèles.

Il mesure ce qu'un modèle fait d'une sortie de terminal lue à voix haute : un résumé court, les faits exacts, rien d'inventé, et le premier mot vite. N'importe quel modèle local peut s'y mesurer.
