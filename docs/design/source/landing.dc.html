01 · L'idée

Un lecteur d'écran lit tout. steph dit ce qui compte.

Votre lecteur d'écran reste indispensable : il lit tout, ligne après ligne. Dans un terminal, c'est souvent trop. steph s'ajoute à lui et résume chaque commande en une phrase.

03 · Local

Rien ne quitte votre machine.

  • Le modèle de langue tourne sur votre ordinateur.
  • La voix est générée sur place.
  • Aucune télémétrie. Aucun compte. Aucune clé d'API.
  • Après l'installation, steph fonctionne hors ligne.
  • Si le modèle s'arrête, steph le relance et résume sans lui en attendant.

Le code est public : vous pouvez le vérifier. Voir le code source

04 · Le modèle

Un petit modèle, entraîné pour ça.

Des règles écrites en code résument une grande partie des sorties. Pour le reste, steph-speak, un petit modèle de langue, dit l'essentiel. Il tourne sur un portable sans carte graphique. Poids, données et banc d'essai sont ouverts.

06 · Entreprises
