[ Shell traduit en parole humaine ]

Le terminal, à voix haute.

steph écoute tout ce qui passe dans le shell et dit l'essentiel à voix haute, en une phrase. Pensé d'abord pour les personnes malvoyantes.

curl -fsSL https://steph.lsmdx.com/install | sh

Linux et macOS · sans droits administrateur · environ 3 Go

Une phrase, pas quarante lignes
100 % local · rien ne sort
zsh et bash, votre configuration

[ 01 · L'idée ]

Un lecteur d'écran lit tout, ligne après ligne. steph dit ce qui compte, en une phrase.

  • Sans steph

    Une erreur de compilation fait 40 lignes, lues une par une.

    Avec steph

    « Erreur TypeScript : la propriété titel n'existe pas, utilisez title. »

  • Sans steph

    Une mise à jour affiche des centaines de lignes.

    Avec steph

    Un pourcentage, puis « Terminé en 1 minute 24. 12 paquets mis à jour. »

  • Sans steph

    Une question [O/n] se perd dans le flot.

    Avec steph

    « Question : souhaitez-vous continuer ? Oui ou non, oui par défaut. »

  • Sans steph

    Comprendre une erreur oblige à tout relire.

    Avec steph

    On pose la question à voix haute : steph connaît l'historique de la session.

[ 02 · Écouter ]

Quatre commandes, quatre phrases.

La vraie voix de steph, générée sur la machine. Pour ce public, entendre vaut mieux que lire.

01 · Erreur

$ cat /nope

« Erreur 1 : cat: /nope : aucun fichier ou dossier de ce nom. »

0:00 / 0:00

02 · Compilation

$ npm run build

« Erreur TypeScript : la propriété titel n'existe pas, utilisez title. »

0:00 / 0:00

03 · Longue commande

$ sudo apt upgrade

« En cours : mise à jour des paquets. 35 pour cent, décompression de vim-common. Terminé en 1 minute 24. 12 paquets mis à jour. »

0:00 / 0:00

04 · Question

$ [O/n]

« Question : il est nécessaire de prendre 24 Mo. Souhaitez-vous continuer ? Oui ou non, oui par défaut. »

0:00 / 0:00

Voix Piper « siwis ». Les sorties courtes, comme ls /usr, sont lues telles quelles. Dans ssh, python ou psql, steph lit la réponse à chaque commande.

[ 03 · Principes ]

Rapide, discret, privé.

A · Parle tôt

Parle tout de suite.

Les cas simples sont instantanés. Les résumés sont lus phrase par phrase, pendant leur calcul.

B · Rien à réapprendre

Votre shell, tel quel.

steph relance zsh ou bash avec votre configuration habituelle. Vos alias, votre invite, vos habitudes.

C · 100 % local

Aucun cloud.

Le modèle de langue et la voix tournent sur la machine. Rien ne sort. Si le modèle tombe, steph le relance et résume sans lui en attendant.

  • Gemma 4 E2B via llama.cpp
  • GPU si présent, 4 Go de mémoire vidéo suffisent
  • Voix Piper, français
  • apt, dnf, pip, git, docker, cargo, make : étapes et pourcentages annoncés

[ 04 · Au clavier ]

Quatre touches pour tout contrôler.

F7

Ouvre la fenêtre de questions.

F8

Silence immédiat.

F9

Répète la dernière annonce.

F10

Explique en détail la dernière commande.

Sur MacF7 à F10 sont des touches multimédia : maintenez fn

q pourquoi ça a planté ?
Question rapide, sans quitter le shell.
q puis Entrée
Invite de question, apostrophes et guillemets acceptés.
steph ask
Fenêtre de questions dans n'importe quel terminal.
steph say "texte"
Tester la voix.

[ 05 · Conçu avec ]

Conçu et testé avec des personnes malvoyantes.

Pas pour elles, avec elles. Cette page suit la même règle : texte contrasté à 7:1, 19 px minimum, lisible à 400 %, mode sombre, tout au clavier.

[ 07 · Installer ]

Une commande.

Sans droits administrateur. Environ 3 Go à télécharger pour le modèle et la voix.

curl -fsSL https://steph.lsmdx.com/install | sh

Ou à la main, avec uv :

Linux

git clone https://github.com/tutozz/steph
cd steph
./scripts/install.sh
steph

macOS Apple Silicon et Intel

brew install uv llama.cpp sox
git clone https://github.com/tutozz/steph
cd steph
./scripts/install.sh
steph

Limite connue : les applications plein écran (vim, htop, less) sont annoncées, pas lues.
