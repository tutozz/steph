Terminal qui parle

Le terminal, à voix haute.

L'essentiel de chaque commande, en une phrase. En plus de votre lecteur d'écran.

$ curl -fsSL https://steph.lsmdx.com/install | sh

Linux et macOS. Windows n'est pas pris en charge.

Gratuit pour les particuliersLicence entreprise »

01 · L'idée

Un lecteur d'écran lit tout. steph dit ce qui compte.

Votre lecteur d'écran reste indispensable. steph s'ajoute à lui et résume chaque commande en une phrase.

Trois situations, sans steph et avec steph
Sans stephAvec steph
Sans stephUne compilation qui échoue, lue ligne après ligne, trace comprise. Avec steph« Échec. Header.tsx ligne 42 : Property titel does not exist on type Props. Did you mean title? »
Sans stephUne mise à jour : une ligne par étape et par paquet. Avec stephUn pourcentage pendant l'attente, puis : « Terminé en 1 minute 24. 12 paquets mis à jour. »
Sans stephUne question [O/n] perdue dans le flot. Avec steph« Question : souhaitez-vous continuer ? Oui ou non, oui par défaut. »

Exemples tirés de sorties réelles, anonymisées. La durée « 1 minute 24 » est un exemple.

02 · Mesuré

Le premier son arrive en 0,19 seconde.

Installation

≈ 1 Go

Local

100 %

Le modèle de langue et la voix tournent sur votre machine.

Comment ces chiffres sont mesurés
  • Premier son : neuf fois sur dix, steph commence à parler moins de 0,19 seconde après la fin d'une commande. Portable Intel Core i5-7200U, sans carte graphique, 33 sorties réelles rejouées. Mesuré avec une version antérieure de steph-speak et non remesuré : 32 de ces 33 phrases viennent des règles écrites en code, sans le modèle.
  • Installation : mesurée sur macOS dans un compte vierge : 55 secondes et environ 1 Go sur le disque avec le petit modèle (modèle 212 Mo, voix 60 Mo, Python, code et dépendances 450 Mo, cache de téléchargement 260 Mo, supprimable) ; llama.cpp de Homebrew non compté. Le modèle base ajoute 2,43 Go.

03 · Local

Rien ne quitte votre machine.

  • Le modèle de langue tourne sur votre ordinateur.
  • La voix est générée sur place.
  • Aucune télémétrie. Aucun compte. Aucune clé d'API.
  • Après l'installation, steph fonctionne hors ligne.
  • Si le modèle s'arrête, steph le relance et résume sans lui en attendant.

Aucune télémétrie : ni dans le code de steph, ni dans les dépendances qu'il configure (celle d'onnxruntime, utilisée par la voix, est désactivée). Le seul réseau utilisé est celui que vous demandez : installer ou mettre à jour. Le code est public : vous pouvez le vérifier. Voir le code source

04 · Le modèle

Deux modèles, entraînés pour ça.

Des règles écrites en code résument une grande partie des sorties. Pour le reste, steph-speak, un petit modèle de langue, dit l'essentiel. Le petit modèle tourne sur un portable sans carte graphique ; le modèle base (2,43 Go) vise les machines plus rapides. Poids, données et banc d'essai sont ouverts.

Le poids du petit modèle. Un portable sans carte graphique suffit.
223 Mo
Langues prises en charge : français et anglais. Les autres langues ne sont pas encore fiables.
2 langues
Vraies sorties de terminal par langue, pour vérifier qu'il dit juste : compilation, tests, git, réseau… Le banc d'essai est ouvert.
105 cas

09 · Installer

Installer en une commande.

$ curl -fsSL https://steph.lsmdx.com/install | sh
$ steph
  • Sans droits administrateur. Environ 1 Go sur le disque avec le petit modèle (mesuré sur macOS).
  • Prérequis : curl, git, tar. Sur un Linux plus ancien que Debian 13 ou Ubuntu 24.04 : cmake et un compilateur C++, pour construire llama.cpp.
  • Désinstaller : steph uninstall
