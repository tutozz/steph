[ Speaking terminal, everything privately hosted ]

Your terminal, out loud.

steph listens to everything in your shell and says what matters out loud, in one sentence. Built first for people with low vision.

curl -fsSL https://steph.lsmdx.com/install | sh

Linux and macOS · no admin rights · about 3 GB · French voice for now

[ 01 · The idea ]

A screen reader reads everything, line by line. steph says what matters, in one sentence.

  • Without steph

    A build error runs 40 lines, read one by one.

    With steph

    “TypeScript error: property titel does not exist, use title.”

  • Without steph

    An update prints hundreds of lines.

    With steph

    A percentage, then “Done in 1 minute 24. 12 packages updated.”

  • Without steph

    A [Y/n] prompt gets lost in the stream.

    With steph

    “Question: do you want to continue? Yes or no, yes by default.”

  • Without steph

    Understanding an error means rereading everything.

    With steph

    Ask out loud: steph knows the whole session history.

[ 02 · Listen ]

Four commands, four sentences.

The real voice of steph, generated on the machine. Recordings are in French, as steph speaks today; English translations are shown.

01 · Error

$ cat /nope

“Error 1: cat: /nope: no such file or directory.”

0:00 / 0:00

02 · Build

$ npm run build

“TypeScript error: property titel does not exist, use title.”

0:00 / 0:00

03 · Long command

$ sudo apt upgrade

“In progress: updating packages. 35 percent, unpacking vim-common. Done in 1 minute 24. 12 packages updated.”

0:00 / 0:00

04 · Prompt

$ [Y/n]

“Question: 24 MB of space is needed. Do you want to continue? Yes or no, yes by default.”

0:00 / 0:00

Piper voice “siwis”, French. Short output like ls /usr is read as is. Inside ssh, python or psql, steph reads each reply.

[ 03 · Principles ]

Fast, quiet, private.

A · Speaks early

Speaks right away.

Simple cases are instant. Summaries are read sentence by sentence while they are computed.

B · Nothing to relearn

Your shell, as is.

steph starts zsh or bash with your usual configuration. Your aliases, your prompt, your habits.

C · 100% local

No cloud.

The language model and the voice run on your machine. Nothing leaves. If the model crashes, steph restarts it and summarizes without it meanwhile.

  • Gemma 4 E2B via llama.cpp
  • GPU if present, 4 GB of VRAM is enough
  • Piper voice, French
  • apt, dnf, pip, git, docker, cargo, make: steps and percentages announced

[ 04 · Keyboard ]

Four keys to control everything.

F7

Opens the question window.

F8

Instant silence.

F9

Repeats the last announcement.

F10

Explains the last command in detail.

On MacF7 to F10 are media keys: hold fn

q why did it crash?
Quick question, without leaving the shell.
q then Enter
Question prompt, apostrophes and quotes accepted.
steph ask
Question window in any terminal.
steph say "text"
Test the voice.

[ 05 · Built with ]

Designed and tested with people with low vision.

Not for them, with them. This page follows the same rule: 7:1 text contrast, 19 px minimum, readable at 400%, dark mode, fully keyboard operable.

[ 07 · Install ]

One command.

No admin rights. About 3 GB to download for the model and the voice.

curl -fsSL https://steph.lsmdx.com/install | sh

Or by hand, with uv:

Linux

git clone https://github.com/tutozz/steph
cd steph
./scripts/install.sh
steph

macOS Apple Silicon and Intel

brew install uv llama.cpp sox
git clone https://github.com/tutozz/steph
cd steph
./scripts/install.sh
steph

Known limit: full-screen apps (vim, htop, less) are announced, not read.
