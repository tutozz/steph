01 · The idea

A screen reader reads everything. steph says what matters.

Your screen reader stays essential. steph works alongside it and sums up each command in one sentence.

Three situations, without steph and with steph
Without stephWith steph
Without stephA failing build, read line by line, stack trace included. With steph“Failed. Header.tsx line 42: Property titel does not exist on type Props. Did you mean title?”
Without stephAn upgrade: one line per step and per package. With stephA percentage while you wait, then: “Done in 1 minute 24. 12 packages upgraded.”
Without stephA [Y/n] prompt lost in the flow. With steph“Question: do you want to continue? Yes or no, yes by default.”

Examples taken from real output, anonymized and translated from French. “1 minute 24” is an example.

How these numbers are measured
  • First sound: nine times out of ten, steph starts speaking less than 0.19 seconds after a command ends. Intel Core i5-7200U laptop, no graphics card, 33 real command outputs replayed. Measured with an earlier version of steph-speak and not re-measured: 32 of these 33 sentences come from rules written in code, without the model.
  • Install: measured on macOS in a fresh account: 55 seconds and about 1 GB on disk with the small model (model 212 MB, voice 60 MB, Python, code and dependencies 450 MB, download cache 260 MB, removable); llama.cpp from Homebrew not counted. The base model adds 2.43 GB.

03 · Local

Nothing leaves your machine.

  • The language model runs on your computer.
  • The voice is generated on the spot.
  • No telemetry. No account. No API key.
  • After install, steph works offline.
  • If the model stops, steph restarts it and summarizes without it meanwhile.

No telemetry: not in steph's own code, not in the dependencies it configures (onnxruntime's telemetry, used by the voice, is disabled). The only network used is the one you ask for: installing or updating. The code is public: check it yourself. See the source code

Protocol and provenance

Steph quality bench: hidden test split of bench v3, 654 cases, 3 seeds, score out of 100. “Current bench”: the steph models and the original Gemma. “Previous bench”: previous version of the harness; the original Gemma scores 60.7 there against 60.6, so compare within one point. Each model reads the prompt of its production profile: short for the small model, generic for the others.

Base model against original Gemma: +3.45 points, 95% interval +1.98 to +4.91 (full file); the shipped file is 0.37 point below the full file (not significant). The small model gains 2.35 points over its previous version (50.6). Inventions: Qwen3.5 9B judge; 3 seeds for the current bench and for Gemma, one for the Qwen models; base model against Gemma: no significant difference.

First word, 9 times out of 10, on the slow laptop. Raw models were measured with a simpler prompt than the production one: order of magnitude. Small model: 36 cases; base model: 51 summaries. The Mac only timed raw models. The base model is too slow on this CPU; it is for fast machines.

GGUF files in Q4_K_M or Q4_0 depending on the model. Peak memory measured on the i5 laptop, except Qwen3.5 9B (Mac M3 Pro, shared memory). The small model runs with -c 8192 --parallel 2 --cache-ram 0; the base model and the original Gemma with the base model's production settings. Qwen3.5 9B labeled part of the training data. File sizes and qualities of the raw Qwen and Granite models: bench/matrix/results/v3-rescore/x3-table.md.

On the Linux PC, the Speak Bench score varies by about 2 points depending on whether the CPU or the graphics card runs the model. These scores follow the steph protocol, with its training prompt; the bench's public leaderboard uses another prompt. The base model's VRAM was not measured: it ran on the CPU.

Fine-tuning: real terminal outputs, anonymized, labeled by Qwen3.5 27B (and 9B for the rest), filtered by a judge that drops invented sentences. steph setup measures how fast the machine is and picks the model. Figures come from files in the repository: docs/readme-charts.

Models under Apache 2.0. Benchmark data under CC BY 4.0. The steph source code is available; its license is separate, see below. Datasets: training set, benchmark.

09 · Install

Install with one command.

$ curl -fsSL https://steph.lsmdx.com/install | sh
$ steph
  • No admin rights. About 1 GB on disk with the small model (measured on macOS).
  • Requirements: curl, git, tar. On Linux older than Debian 13 or Ubuntu 24.04: cmake and a C++ compiler, to build llama.cpp.
  • Uninstall: steph uninstall
